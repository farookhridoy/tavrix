Everything you reach for, together

No separate SFTP client. No copy-pasting paths between windows.

Terminal

Several shells on one connection, side by side or stacked. Drag the dividers to resize. Themes, fonts and scrollback.

File manager

Click to open folders, drag files in from your computer to upload, right-click to download, rename or change permissions. Scripts stay executable.

Editor with tabs

Syntax highlighting, auto-save, and a warning if someone changed the file on the server. One click makes a script executable.

Sessions, kept safe

Save servers in folders. Passwords and key passphrases are encrypted with your system's secure storage (the macOS Keychain, or Windows' own protection). Import from ~/.ssh/config.

Jump hosts and tunnels

Reach private servers through a bastion. Local, remote and SOCKS5 port forwarding from a simple form.

Snippets

Save commands you type often and insert them with a click. Nothing runs until you press Enter.

Safe by default

Server fingerprints are checked and a changed key is blocked. One network connection per session. No accounts, no telemetry.

Light

About 90 MB to download, trimmed down from a much bigger default. Comes with a quick tour and a built-in manual.

How to install and open Tavrix

Tavrix is not signed by a paid Apple Developer account, so macOS says "Apple could not verify Tavrix is free of malware" the first time you open it. The app is open source, and nothing is wrong with your download. You only need to do this once.

  1. 1
    Install

    Open the downloaded .dmg and drag Tavrix into Applications.

  2. 2
    Open it once

    Open Tavrix from Applications. macOS shows the warning. Click Done. Do not click Move to Trash.

  3. 3
    Allow it

    Open System Settings → Privacy & Security, scroll down to Security, click Open Anyway next to Tavrix and enter your password.

  4. 4
    Use it

    Open Tavrix again and click Open. Click + to add your first server. A short tour starts by itself.

Prefer Terminal? Run this once, then open Tavrix normally:

xattr -dr com.apple.quarantine /Applications/Tavrix.app

Saw "Tavrix is damaged" or "Not Opened" instead? It is the same thing and the same fix.

Tavrix is not signed with a paid Windows certificate, so your browser and Windows SmartScreen ask you to confirm it the first time. The app is open source, and nothing is wrong with your download. You only need to do this once.

  1. 1
    Download

    Download the .exe installer. If your browser says it is not commonly downloaded, choose Keep, then Keep anyway.

  2. 2
    Run it

    Double-click the installer. If Windows shows "Windows protected your PC", click More info, then Run anyway.

  3. 3
    Install

    Pick where to install (the default is fine) and finish. Tavrix is added to the Start menu.

  4. 4
    Use it

    Open Tavrix from the Start menu and click + to add your first server, or SFTP for a files-only session. A short tour starts by itself.

Keys that clash with the terminal are different on Windows: panels use Ctrl+Shift+B and Ctrl+Shift+E, and Ctrl+C copies only when text is selected (otherwise it interrupts the running program).

How do I verify that my download is genuine?

Compare the SHA-256 shown above with your file's.

On a Mac (Terminal):

shasum -a 256 ~/Downloads/Tavrix-*.dmg

On Windows (PowerShell):

Get-FileHash "$HOME\Downloads\Tavrix-*.exe" -Algorithm SHA256

You can also read the source and build it yourself: build instructions.

Questions

Is it really free?

Yes. Tavrix is open source under the MIT license. There are no accounts and no paid tier.

Does it send my data anywhere?

No telemetry, no analytics. Its only automatic network request is an anonymous check for a newer version on GitHub, which you can turn off. Passwords are encrypted with the macOS Keychain, and everything else goes only to the servers you connect to.

Is there a Linux version?

Not at the moment. Tavrix is built for {{platforms}}.

Where do I learn how to use it?

A quick tour starts on first launch, and the Manual button inside the app opens the full documentation. The same pages are online in the manual on GitHub.

My server blocks my IP after a few minutes. Is that Tavrix?

That is usually a security rule on the server (such as fail2ban) or its provider. Tavrix uses a single connection per session, so it makes fewer connections than most tools. The manual's troubleshooting section shows how to find the cause.
